# AutoPrintCode: новый вид и доработки

Дата: 2026-10-07. Платформа остаётся прежней: Python + PySide6 (решение пользователя).

## Цель

Стабильное и красивое приложение в стиле PasteTalk: тёмный графит, один янтарный акцент,
карточки из строк, свой заголовок окна. Внутри — удобная печать кода для уроков и видеогайдов.

## Этапы

1. **Внешний вид** (этот документ подробно) — весь интерфейс в стиле PasteTalk.
2. **Основа**: запуск exe (PyInstaller), автообновление exe с GitHub, трей (свернуть в трей,
   закрепить значок у часов как в NoVPN), автозапуск, исправление найденных ошибок стабильности.
3. **Печать**: пресеты скорости, новый «Как человек» (опечатки на 100 символов), построчный режим.
4. **Пошаговая печать** (режим преподавателя).
5. **Запись звука своей клавиатуры** через микрофон.

### Главное окно

- **Свой заголовок** (как в PasteTalk): логотип, «AutoPrintCode», точка и текст состояния
  («Готов», «Печатает · Решение · строка 2 из 5»). Справа закреплены кнопки ⚙ «Настройки» и
  ⓘ «О программе», затем «Свернуть / Развернуть / Закрыть». Щелчок по логотипу открывает меню:
  Настройки, О программе, Проверить обновления, Журнал работы, Папка с данными, Выход.
  Окно остаётся «настоящим» окном Windows: прилипание к краям, растягивание, тень, двойной
  щелчок по заголовку.
- **Слева** — библиотека образцов (как меню разделов PasteTalk): поиск, список с числом блоков,
  янтарная черта у выбранного, внизу «＋ Новый» и «Импорт». Вкладок больше нет: открытый образец —
  выбранный в списке. Ctrl+Tab / Ctrl+1…9 переключают образцы.
- **Сверху справа — пульт** (карточка, не прокручивается):
  - строка 1: большая кнопка «Старт/Пауза/Продолжить» с хоткеем, «Сначала», «Стоп»,
    скорость «Медленно / Стандарт / Быстро» (180 / 320 / 600 зн/мин) и точное число,
    переключатели «Как человек» и «Без комментариев»;
  - строка 2: состояние и куда печатаем, полоса хода, «2 / 5 строк», звук и громкость, профиль окна.
- **Лента блоков** под пультом: текстовые блоки — заметки с цветной чертой роли, блоки кода —
  карточки с редактором. Активный блок обведён акцентом. Во время печати в активном блоке уже
  напечатанное яркое, остальное приглушено, текущее место отмечено.
- Сообщения — всплывающие «тосты» внизу окна вместо строки состояния. Меню-полоски нет.

### Окно настроек (как в PasteTalk)

Отдельное окно со своим заголовком. Слева разделы: Печать, Как человек, Звук, Горячие клавиши,
Поведение, Вид, Обновления, О программе. Справа страница: заголовок, пояснение, группы
карточек со строками «значок · название · пояснение · элемент управления». Изменения
применяются и сохраняются сразу, кнопки «ОК» нет. Хоткей записывается щелчком по полю;
пока идёт запись, глобальные хоткеи отключены; повтор сочетания подсвечивается.

### Логотип

Строки кода с курсором (выбран пользователем). Значок приложения — янтарный знак на
графитовой плитке. В трее знак без плитки, три состояния: «Готов» — контур, «Печатает»
(и отсчёт) — залитая плитка, «Пауза» — две черты. Окно при печати не меняется,
плашки поверх окон нет.

## Этапы 2–5 — сделаны 2026-10-08

Итоговые решения (отличия от первоначальных набросков ниже):
- **По шагам**: шаг — у каждой строки (Block.steps, хранится в данных строк редактора и «едет» с ними
  при правке). Шаг k вставляет свои строки кусками; к месту — абсолютно: Ctrl+Home → ↓ / Ctrl+End → ↑,
  End, Enter (в самый верх: Ctrl+Home, Enter, ↑). Первый шаг — где курсор. Комментарии шага — текст
  суфлёра; шаг из одних комментариев пропускается с подсказкой. Логика — `autoprint/steps.py`,
  проверка — `tests/test_steps.py` (эмулятор редактора, 400 случайных разметок).
- **Суфлёр** — карточка под пультом (не плашка поверх окон): что дальше и что сказать.
- **По строкам**: перед Enter — очистка справа (IDE), затем ожидание; физический Enter пользователя
  ловится хуком клавиатуры без поглощения (`guard.watch_enter`), хоткей — альтернатива.
- **Трей**: «сворачивать в трей», «значок у часов» (IsPromoted, отключаемо), автозапуск `--tray`,
  один экземпляр через QLocalServer.
- **Звук**: мастер записи любой клавиатуры (`recorder.py`, `ui/record_dialog.py`), сборка звука в фоне.

### Первоначальные наброски

- **Трей**: «Сворачивать в трей при закрытии», «Держать значок у часов» (реестр
  `HKCU\Control Panel\NotifyIconSettings\*\IsPromoted=1` по пути exe, как в NoVPN, но
  отключаемо). Значок меняется по состоянию печати.
- **Exe и обновления**: сборка PyInstaller (папка + установщик Inno Setup), обновление — скачать
  установщик релиза с GitHub, проверить SHA-256, тихо поставить и перезапустить.
- **Опечатки**: частота «N на 100 символов» (по умолчанию 2), виды: соседняя клавиша, пропуск,
  перестановка, двойное нажатие, лишний пробел; замечаются через 0–3 символа; бывают и в
  идентификаторах; не задевают скобки, кавычки, отступы и Enter. Итог всегда совпадает с образцом.
- **Построчно**: хоткей печатает одну строку; Enter — следующая; пустые строки проходят сами.
- **Пошагово**: в блоке кода шаги размечаются в поле слева от номеров строк (шаг 1, 2, 3 …);
  каждый шаг — набор строк, возможно в середине уже напечатанного. Печать шага: курсор
  переходит к нужному месту (Ctrl+Home + стрелки) и печатает строки шага.
- **Свой звук**: мастер «Записать мою клавиатуру»: обычные клавиши, пробел, Enter, Backspace;
  нарезка ударов по пикам громкости; набор сохраняется как ещё один стиль звука.
